# AeroTrack

**Tracker GPS open-source pour le parapente et le vol libre** : il transmet la position du pilote à la FFVL (VLSafe), même sans réseau mobile, par une station base et le relais entre pilotes, et le rend visible sur le réseau OGN.

## 📥 Installer

| Je veux… | Où |
|---|---|
| **Installer le logiciel sur une carte** (Chrome ou Edge, câble USB) | **[diyeveryday.github.io/aerotrack/installateur](https://diyeveryday.github.io/aerotrack/installateur/)** |
| **L'application Android** (elle se met ensuite à jour toute seule) | **[AeroTrack-Android.apk](https://diyeveryday.github.io/aerotrack/app/AeroTrack-Android.apk)** |

Cartes prises en charge : Heltec WiFi LoRa 32 V2, Heltec Wireless Tracker, LILYGO T-Beam, LoRa32 V2.1, T-Echo, T-Watch 2019 + S76G (trackers) et T-SIM7000G (station base 4G).

## Ce dépôt

Il héberge le **site de téléchargement** (branche `gh-pages`, publiée à chaque nouvelle version). Il deviendra le dépôt officiel du projet, avec le code source et le manuel.

## Avertissement

AeroTrack est un **outil d'aide** à la sécurité, **pas un dispositif de secours** : le SOS **n'appelle pas les secours**. En cas d'urgence, composer le **112**.
