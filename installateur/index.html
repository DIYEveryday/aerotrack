AeroTrack

Installer le logiciel sur votre carte

Un câble USB, le navigateur Chrome ou Edge sur un ordinateur, deux minutes. Rien à installer sur l'ordinateur.

Ce navigateur ne peut pas parler à la carte. Ouvrez cette page dans Google Chrome ou Microsoft Edge, sur un ordinateur (Windows, Mac ou Linux). Les téléphones, Firefox et Safari ne le permettent pas.

Page ouverte depuis l'ordinateur. Les logiciels ne se téléchargent pas ici : choisissez votre carte puis, à l'étape 3, ouvrez « Avancé » et sélectionnez le fichier .bin du dossier binaires du projet. La page en ligne, elle, s'occupe de tout.

  1. Branchez la carte à l'ordinateur avec un câble USB de données (certains câbles ne font que charger).
  2. Cliquez sur le bouton, puis choisissez la carte dans la fenêtre du navigateur (souvent « USB Serial », « CP210x », « CH9102 » ou « ESP32-S3 »).
Préparation…0 %
  1. Téléchargez le logiciel du T-Echo : AeroTrack pour T-Echo (.uf2)
  2. Branchez le T-Echo en USB, puis appuyez deux fois rapidement sur son bouton reset : un lecteur TECHOBOOT apparaît, comme une clé USB.
  3. Glissez le fichier sur ce lecteur. Le T-Echo redémarre tout seul sous AeroTrack ; le lecteur disparaît, c'est normal.
